# 🤖 Automação de Consultas em Lote

Este projeto é uma automação desenvolvida em Python com o objetivo de otimizar um processo manual de consultas em lote, tornando-o mais rápido, prático e portátil.

O sistema foi evoluído para um executável (.exe), permitindo sua execução em qualquer máquina Windows sem necessidade de instalação de Python ou dependências adicionais.

---

## 🚀 Objetivo

Automatizar um fluxo de consultas que antes era feito manualmente, reduzindo tempo operacional e esforço humano.

---

## ⚙️ Funcionalidades

- Automação de fluxo de consultas
- Processamento em lote de dados
- Integração com navegação automatizada (Playwright)
- Exportação e organização de resultados
- Execução como aplicativo standalone (.exe)

---

## 🔧 Tecnologias utilizadas

- Python
- Play wright
- Pandas (se você estiver usando Excel)
- PyInstaller (para gerar o executável)
